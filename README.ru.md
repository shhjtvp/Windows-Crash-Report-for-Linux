## Введение

**Crash Simulator** — это Python-программа для Linux-десктопов, которая:

1. **Отслеживает** процессы, запущенные текущим пользователем, и определяет момент их завершения.  
2. При завершении процесса **показывает** окно в стиле Windows — «Отчёт об ошибке Microsoft Windows».  
3. После нажатия кнопки «Отправить» имитирует отправку отчёта (на самом деле просто выполняет `ping microsoft.com`).  
4. Идеально воспроизводит «окно краша» для Windows-пользователей — отлично подходит для розыгрышей друзей.

## Установка

### Зависимости

- Python 3.6 или новее  
- pip (менеджер пакетов Python)  
- Десктопное окружение (GNOME / KDE / XFCE и т.п., с поддержкой `~/.config/autostart`)

### Онлайн-установка

Установка последней версии напрямую с GitHub:
```bash
pip install git+https://github.com/shhjtvp/Windows-Crash-Report-for-Linux.git
```
Если не хотите использовать `sudo`, добавьте `--user` для установки только для текущего пользователя:
```bash
pip install --user git+https://github.com/shhjtvp/Windows-Crash-Report-for-Linux.git
```
После установки появятся две утилиты командной строки:  
- `crash-sim` — запуск основной программы  
- `crash-sim-setup` — мастер настройки (предупреждение, автозапуск)

### Локальная установка

Если вы клонировали репозиторий:
```bash
git clone https://github.com/shhjtvp/Windows-Crash-Report-for-Linux.git
cd Windows-Crash-Report-for-Linux
pip install .
```
Также можно добавить `--user`.

### Проверка установки
```bash
which crash-sim
```
Если отображается путь — установка прошла успешно.

## Первоначальная настройка

**Важно!** После установки необходимо запустить команду настройки, чтобы подтвердить прочтение предупреждения и выбрать автозапуск:
```bash
crash-sim-setup
```
Вы увидите:
```text
============================================================
  ПРЕДУПРЕЖДЕНИЕ: Этот скрипт только для технических
  демонстраций и развлечения, мяу~
  Используйте на свой страх и риск, ня~
  Не запускайте на физическом оборудовании!
============================================================
```
- Введите `y` или `yes` → включить автозапуск (только для текущего пользователя)  
- Введите `n` или `no`, или просто нажмите Enter → не включать автозапуск, только подтвердить предупреждение

## Использование

### Запуск мониторинга
```bash
crash-sim
```
После запуска программа в фоне отслеживает все процессы текущего пользователя. При закрытии любого приложения (Firefox, Chrome, терминал и т.д.) немедленно появляется окно, имитирующее отчёт об ошибке Windows.

### Остановка
Нажмите `Ctrl + C` для выхода из программы, или просто закройте окно терминала.

### Автозапуск
Если при настройке вы включили автозапуск, `crash-sim` будет автоматически запускаться в фоне при каждом входе в систему. Вы можете увидеть процесс `crash-sim` в системном мониторе или остановить его вручную командой:
```bash
killall crash-sim
```

## Удаление

### 1. Очистка автозапуска
```bash
crash-sim-setup --uninstall
```
Эта команда удаляет файл `~/.config/autostart/crash-sim.desktop` (если он существует).

### 2. Удаление пакета Python
```bash
pip uninstall crash-simulator
```
Если устанавливали с `--user`, добавьте его же:
```bash
pip uninstall crash-simulator --user
```

### Полная очистка
Для удаления всех связанных файлов можно также удалить следующие директории (если они есть):
```bash
rm -rf ~/.cache/crash-sim          # кеш
rm -rf ~/.config/crash-sim         # конфигурация
```

> 💡 Подсказка: используйте `pip show crash-simulator`, чтобы узнать, где установлен пакет.

## Совместимость с десктопными окружениями

*Чтобы каждый пользователь Linux мог попробовать это 💩*

По умолчанию используется каталог `~/.config/autostart/` (стандарт freedesktop.org), поддерживаемый большинством популярных десктопных окружений.

### Поддерживаемые окружения

| Окружение | Автозапуск | Примечания |
|-----------|------------|------------|
| **GNOME** (3.x/40+) | ✅ Полная | Стандартный каталог `autostart` |
| **KDE Plasma** | ✅ Полная | То же |
| **XFCE** | ✅ Полная | То же |
| **Cinnamon** | ✅ Полная | То же |
| **MATE** | ✅ Полная | То же |
| **LXDE / LXQt** | ✅ Полная | То же |
| **i3 / Sway / Awesome** (WM) | ⚠️ Ограниченная | Требуется ручная настройка (см. ниже) |
| **Deepin / Unity** | ✅ Полная | То же |

### Оконные менеджеры (i3 / Sway / Awesome и др.)

Если вы используете чистый оконный менеджер (не полное десктопное окружение), `.desktop`-файлы из `~/.config/autostart` **не будут выполняться автоматически**. Нужно вручную добавить команду запуска в конфигурационный файл оконного менеджера.

**Пример (i3):** отредактируйте `~/.config/i3/config`, добавьте:
```
exec --no-startup-id crash-sim
```

**Пример (Sway):** отредактируйте `~/.config/sway/config`, добавьте:
```
exec crash-sim
```

**Пример (Awesome WM):** отредактируйте `~/.config/awesome/rc.lua`, добавьте:
```lua
awful.spawn.with_shell("crash-sim")
```

### Ручное управление автозапуском (универсально)

Если вы хотите полностью ручной контроль:
1. Запустите `crash-sim-setup` и выберите **не включать** автозапуск.  
2. Запускайте вручную, когда нужно: `crash-sim &` (в фоне).  
3. Можно добавить `crash-sim` в конфигурацию оболочки (например, `~/.bashrc`), но **не рекомендуется**, так как при каждом открытии терминала будет запускаться новый процесс мониторинга, что приведёт к пустой трате ресурсов.

## Часто задаваемые вопросы

> **Вопрос: Как временно отключить мониторинг?**  
> **Ответ:** Нажмите `Ctrl + C`, чтобы завершить программу. Если хотите приостановить мониторинг без перезапуска, можно убить процесс Python или добавить метод `pause()` в `ProcessMonitor` (в текущей версии такого нет).

> **Вопрос: Автозапуск не работает?**  
> **Ответ:** Проверьте:  
> 1. Существует ли файл `~/.config/autostart/crash-sim.desktop` и правильное ли его содержимое.  
> 2. Есть ли у файла права на выполнение (обычно не требуется, но можно `chmod +x`).  
> 3. Поддерживает ли ваше десктопное окружение стандарт `autostart` (см. таблицу выше).  
> 4. Перезапустите сессию (или выйдите и зайдите заново) — некоторые окружения сканируют `autostart` только при входе.  
> 5. Проверьте, работает ли `crash-sim` вручную.

> **Вопрос: После удаления осталась запись в автозапуске?**  
> **Ответ:** Убедитесь, что вы сначала выполнили `crash-sim-setup --uninstall`, а потом удаляли пакет. Если пакет уже удалён, удалите файл вручную:
> ```bash
> rm -f ~/.config/autostart/crash-sim.desktop
> ```

> **Вопрос: Работает ли под Wayland?**  
> **Ответ:** Да, программа не зависит от X11. Однако обратите внимание, что команда `ping` может требовать возможности `CAP_NET_RAW` или setuid-бит. Если `ping` не сработает, программа сообщит об «ошибке отправки», но окно будет появляться как обычно.
