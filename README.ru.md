## Особенности

-   **Пиксельная точность:** Создано с использованием Qt, точно воспроизводя закруглённые углы, тени, шрифты и анимации взаимодействия в стиле Win11.
-   **Кроссплатформенная поддержка:** Автоматическая адаптация флагов окон и стилей в Windows / Linux (X11/Wayland).
-   **Симуляция мониторинга процессов:** Опциональный фоновый режим демона, который автоматически вызывает всплывающее окно при завершении указанного процесса.
-   **Безопасность и защита от ошибок:** Все всплывающие окна содержат водяной знак `[Simulation]`, чтобы их нельзя было принять за реальные системные сбои.

## Начало работы

### Установка

```bash
pip install Windows-Crash-Report-for-Linux
```

### Первый запуск

```bash
crash-simulator
```

При первом запуске программа выведет предупреждение о безопасности в терминале и потребует ручного ввода `YES` для подтверждения.
Это гарантирует, что вы понимаете развлекательный характер и потенциальное влияние этого проекта. Программа откажется запускаться в неинтерактивных средах.

### Основные команды

```bash
# Немедленно вызвать симулированное окно ошибки
crash-simulator pop

# Запустить режим фонового мониторинга (отслеживание конкретного PID)
crash-simulator monitor --pid 12345

# Включить/Отключить автозагрузку
crash-simulator autostart --enable
crash-simulator autostart --disable

# Очистка всех конфигураций и остаточных файлов одной командой
crash-simulator cleanup --yes
```

## Разработка

```bash
# Клонировать репозиторий (длинное имя — часть плана)
git clone https://github.com/shhjtvp/Windows-Crash-Report-for-Linux.git
cd crash-simulator

# Создать виртуальную среду и установить зависимости для разработки
python -m venv .venv && source .venv/bin/activate  # Linux/macOS
# .venv\Scripts\activate                            # Windows

pip install -e ".[dev]"

# Локальный запуск
python -m crash_simulator
```
